## ❓ NẾU VẪN LỖI

### Lỗi: Categories vẫn không hiển thị
**Giải pháp:**
```bash
# Xóa HOÀN TOÀN app và data
adb uninstall com.example.bookstore

# Cài lại
adb install app\build\outputs\apk\debug\app-debug.apk
```

### Lỗi: Titles vẫn cũ/blank
**Nguyên nhân:** Database cũ vẫn còn
**Giải pháp:**
1. Settings → Apps → Bookstore → Storage → Clear Data
2. Hoặc: `adb shell pm clear com.example.bookstore`
3. Mở app lại

### Lỗi: App crash khi mở
**Giải pháp:**
1. Kiểm tra logcat: `adb logcat | findstr "BookStore"`
2. Rebuild: `.\gradlew.bat clean assembleDebug`
3. Reinstall
